INTEGRATION

Sector
Malaria / IRS
Client
National MoH
Role
Systems Architect
Timeline
Pre-campaign build

The challenge

Ahead of an active indoor residual spraying campaign, the national Ministry of Health needed a way to capture and manage IRS-specific data inside their existing DHIS2 instance — without disrupting the program structures already in use for other interventions.

The system had to be ready before spray teams deployed, work within the Ministry's existing data governance, and produce data clean enough to drive real-time campaign decisions rather than just retrospective reporting.

The approach

I designed and built a customized IRS module inside the national DHIS2 instance, tailored to the Ministry's program structure and reporting hierarchy rather than a generic template.

  • Mapped IRS data requirements against existing metadata structures
  • Designed program stages, data elements, and validation rules for spray operations
  • Built and tested the module against the Ministry's org hierarchy
  • Coordinated rollout timing against the campaign calendar

The outcome

The module was live and validated ahead of the campaign start date, giving the Ministry a single, integrated place to manage IRS data alongside its other malaria programs — rather than a parallel system that would eventually need to be reconciled back in.

Stack

DHIS2 Tracker Program Rules PostgreSQL

Context

Built inside a live national instance already supporting multiple malaria interventions, with campaign timelines that left no room for delay.

Required close coordination with Ministry counterparts to ensure the module fit existing workflows rather than requiring spray teams to learn a parallel system.
